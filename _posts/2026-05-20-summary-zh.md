## [Mozilla 正式弃用 Asm.js，一个时代落幕](https://spidermonkey.dev/blog/2026/05/20/saying-goodbye-to-asmjs.html) ⭐️ 8.0/10

Mozilla 宣布正式弃用 Asm.js，这一开创性的 JavaScript 子集曾让 C/C++ 代码在浏览器中接近原生性能。SpiderMonkey 团队的博客文章标志着对该技术支持的中止。 Asm.js 为如今主导高性能 Web 应用的二进制格式 WebAssembly 铺平了道路。它的弃用标志着完全过渡到 WebAssembly，后者具有更小的包大小和更快的解析速度。 Asm.js 代码仍然是有效的 JavaScript 并可继续运行，但 Mozilla 将不再对其进行优化。像 Emscripten 这样的工具多年来已默认输出 WebAssembly。

hackernews · eqrion · May 20, 12:01 · [社区讨论](https://news.ycombinator.com/item?id=48206340)

**背景**: Asm.js 是 JavaScript 的一个严格子集，专为性能设计，允许通过 Emscripten 编译的 C/C++ 代码在浏览器中运行。它由 Mozilla 于 2013 年提出，作为 Google 的 NaCl/PNaCl 的替代方案，证明了 Web 可以达到接近原生的速度。WebAssembly 作为标准化的二进制格式接替了它，提供更好的性能和更小的文件体积，现已获得所有主流浏览器的支持。

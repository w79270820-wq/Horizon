## [加拿大悄然签署联合国网络犯罪公约 引发监控担忧](https://www.michaelgeist.ca/2026/07/a-surveillance-treaty-in-disguise-the-trouble-with-canadas-quiet-decision-to-sign-the-un-cybercrime-convention/) ⭐️ 8.0/10

加拿大悄然签署了《联合国网络犯罪公约》，隐私学者 Michael Geist 谴责此举是披着打击网络犯罪外衣的监控条约。此次签署几乎没有公开辩论，尽管该公约赋予广泛的电子监控权力。 该公约是首个全球综合性网络犯罪公约，但批评者警告其宽泛的调查和证据共享条款可能被政府滥用，以扩大监控范围。加拿大签署该公约可能使这些权力在民主国家中常态化，并直接影响加拿大人的隐私以及记者、活动家和安全研究人员的处境。 《联合国网络犯罪公约》又称“河内公约”，于 2024 年 12 月通过，2025 年开放签署。仅签署并不对国家产生约束力，还需进行批准；由于人权保障不足，该公约遭到人权组织和科技公司的反对。

hackernews · iamnothere · Aug 1, 14:19 · [社区讨论](https://news.ycombinator.com/item?id=49134694)

**背景**: 网络犯罪公约旨在协调各国法律，并促进数字犯罪调查方面的合作。然而，这项由俄罗斯于 2017 年提出的公约因其监控和证据共享措施扩展到网络犯罪之外的严重犯罪，且缺乏对人权的强有力保护而受到批评。批评者还担心它可能被用来将记者和研究人员的受保护活动定罪。签署与批准条约之间的区别很重要：签署表明意图，而批准则使其具有法律约束力。

## [OpenAI 报告数学与理论计算机科学十项进展](https://openai.com/index/ten-advances-in-mathematics/) ⭐️ 8.0/10

OpenAI 发布了一篇博客文章，介绍其 AI 模型在数学和理论计算机科学领域取得的十项进展，据称该模型解决这些被重点提及的问题每个耗时成本约 2,000 美元。这篇博文很快引发了社区对实验透明度和证明意义的质疑。 这件事之所以重要，是因为它表明 AI 系统现在可能不仅限于解决基准测试题，还能在数学和理论计算机科学领域贡献原创研究成果。如果这些说法经得起检验，可能会改变研究人员的工作方式并加速发现；但报道中缺乏严谨性也可能损害人们对 AI 研究成果的信任。 社区评论者特别问到：总共尝试了多少问题、每个问题尝试了多少次，以及这些证明是引入了新的数学思想，还是仅仅通过穷举搜索来寻找解决方案。如果不完整披露实验设置，所谓“每个问题 2,000 美元”的数字可能会产生误导。

hackernews · OpenAI News · Aug 1, 07:37 · [社区讨论](https://news.ycombinator.com/item?id=49132058)

**背景**: 数学和理论计算机科学历来被视为需要深度人类创造力的领域，因此成为检验人工智能的重要试金石。近年来，大语言模型和专门的推理系统开始帮助进行证明形式化、猜想生成和算法发现，但验证正确性和避免选择性报告仍然是重大挑战。OpenAI 的这篇博文是 AI 实验室宣称研究级进展这一更广泛趋势的一部分，促使研究社区要求更清晰的证据和更可复现的方法。

**社区讨论**: 讨论中既有惊叹也有谨慎：一位评论者指出，我们“不再对 AI 数学进展感到惊讶”，另一位则表示 AI 的影响不可否认。一些评论者担心 OpenAI 的措辞是为了营销而夸大，并且没有披露完整实验过程，导致说辞可信度下降。还有一种观点将这些突破与 AI 快速起飞以及软件性能大幅提升的可能性联系起来。

## [DeepSeek V4-Flash-0731：304B 参数模型，智能性价比领先](https://simonwillison.net/2026/Jul/31/deepseek-v4-flash-0731/#atom-everything) ⭐️ 8.0/10

## [无状态 MCP 2.0 重燃兴趣，催生新工具](https://simonwillison.net/2026/Jul/31/stateless-mcp/#atom-everything) ⭐️ 8.0/10

2026-07-28 发布的 Model Context Protocol 规范（即 Stateless MCP / MCP 2.0）取消了多请求会话握手，让一次 HTTP 请求即可完成工具调用。这一重大更新促使 Simon Willison 开发了 mcp-explorer 和 datasette-mcp。 这是 MCP 自发布以来最重要的一次变更，大幅降低了客户端与服务端的实现复杂度，并去掉了服务端会话状态。它让 MCP 更适合可扩展的 Web 应用以及能在笔记本上运行的小模型，有望在 Claude Skills 抢走风头后重新确立 MCP 的地位。 旧版有状态 MCP 需要两次 HTTP 请求：先用 initialize 获取 Mcp-Session-Id，再调用工具；无状态 MCP 只需一次请求，并通过 MCP-Protocol-Version、Mcp-Method 等头部完成调用。这一改变提升了可见性、可靠性和可扩展性，作者在一周内实现了三个客户端/服务端。

rss · Simon Willison · Jul 31, 23:13

**背景**: MCP 是 Anthropic 于 2024 年 11 月推出的开放标准，用于统一 AI 代理连接外部工具和数据源的方式。2025 年，Claude Skills 因能让拥有终端和 curl 的代理更灵活地完成许多 MCP 任务而受到关注，但直接给代理 shell 环境存在风险；无状态 MCP 让工具更容易审计和控制。

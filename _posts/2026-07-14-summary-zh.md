## [澳大利亚强制要求提供日间免费电力计划](https://lenergy.com.au/free-daytime-electricity-is-coming-heres-how-it-actually-works/) ⭐️ 8.0/10

自 2026 年 7 月 1 日起，拥有超过 1000 名客户的澳大利亚能源零售商必须向新南威尔士州、东南昆士兰州和南澳大利亚州的住宅客户提供至少一项包含 3 小时免费电力（11 点至 14 点）、每日上限 24 千瓦时的计划。 该政策旨在吸收午间太阳能过剩，减少可再生能源弃电并可能降低消费者账单，但也引发了对电网频率稳定性和电池储能经济性的担忧。 免费电力时段限定在太阳能发电高峰期（11 点至 14 点），每日上限 24 千瓦时。部分零售商已提供类似计划，而电池用户的早期采用被怀疑与上午 11 点出现频率下降有关。

hackernews · i2oc · Jul 14, 04:31 · [社区讨论](https://news.ycombinator.com/item?id=48902320)

**背景**: 澳大利亚屋顶太阳能普及迅速，导致午间太阳能发电高峰时出现电力过剩。若不加以平衡，多余电力可能导致电网不稳定。电网储能（尤其是电池）可储存多余太阳能并在需要时放电，有助于维持频率稳定。新政策鼓励在供应过剩时段用电，以减轻电网压力并促进电池采用。

## [Codex 加密子代理提示，对用户隐藏](https://github.com/openai/codex/issues/28058) ⭐️ 8.0/10

OpenAI 更新了 Codex，使其加密子代理提示（sub-agent prompts），从而防止用户在编码工作流中查看或检查发送给下级 AI 代理的提示。 这一变化降低了在 Codex 上构建应用的开发者的透明度和控制力，因为他们无法再审计发送给子代理的指令，这可能阻碍调试、定制和对 AI 辅助编码的信任。 加密专门应用于 Codex 的代理编码框架内发送给子代理的提示，而不是整体推理过程；使用本地检查工具的用户报告说，更新后这些工具在某些情况下已不再工作。

hackernews · embedding-shape · Jul 14, 11:21 · [社区讨论](https://news.ycombinator.com/item?id=48905028)

**背景**: 像 Codex 这样的编码代理使用子代理来执行专门的任务，如代码分析或文件编辑，每个子代理在隔离的上下文中运行。以前，用户可以检查给这些子代理的提示以了解代理的推理过程。现在的加密隐藏了这些信息，这与走向可验证和透明的 AI 工作流的趋势相悖。

## [DOOMQL：完全由 SQLite 驱动的类 Doom 游戏](https://simonwillison.net/2026/Jul/13/doomql/#atom-everything) ⭐️ 8.0/10

开发者 Peter Gostev 构建了 DOOMQL，这是一款类 Doom 的第一人称射击游戏，完全以 SQLite 作为游戏引擎，通过 SQL 查询处理移动、碰撞、战斗和像素渲染。该项目借助 OpenAI 的 GPT-5.6 Sol 模型完成。 该项目展示了将数据库系统用作游戏引擎的激进且创造性的用法，可能为数据驱动型应用和游戏开发带来新思路。同时，它展现了 GPT-5.6 Sol 的高级编码能力，复杂的 SQL 光线追踪器正是在其帮助下生成的。 DOOMQL 实现为一个 Python 终端脚本，使用 uv 包管理器运行，并将所有游戏状态存储在单个 SQLite 数据库文件中。游戏的光线追踪器（用于渲染第一人称视角）实现为一个 750 行的 SQL 查询，使用递归公用表表达式（CTE）。

rss · Simon Willison · Jul 13, 22:34

**背景**: SQLite 是一个轻量级的嵌入式关系数据库管理系统，将数据存储在单个文件中并使用 SQL 进行查询。递归公用表表达式（CTE）允许 SQL 执行迭代计算，从而实现光线追踪等复杂算法。GPT-5.6 Sol 是 OpenAI 最新的旗舰模型，被描述为其最佳编码模型。uv 是一个用 Rust 编写的高性能 Python 包管理器。
